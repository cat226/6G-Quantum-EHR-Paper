# 6G-Enabled Hybrid Quantum-Secure Architecture for Electronic Health Record Sharing

**Authors:** Ramana Sree K V, Verona Ann Mariya

## Overview
This project provides a computational research implementation for evaluating secure Electronic Health Record (EHR) communication in a future 6G-oriented network context. The goal is to study the behavior and properties of such systems. Note that 6G standards are not yet finalized, and this work does not claim that the integration of QKD, PQC, and EHR is inherently novel.

## Repository Structure
- `src/`: Core implementation of protocols, simulations, and metrics.
- `tests/`: Correctness and integration tests.
- `experiments/`: Experiment execution scripts.
- `config/`: Parameters and configuration files.
- `results/`: Outputs from experiments (raw data, processed data, figures).
- `docs/`: Documentation and task requirements.

## Experimental Philosophy
Later experiments will compare explicitly defined security/protocol configurations using reproducible simulation. No experimental results are reported in the current baseline.

## Reproducibility
The project relies on configuration-driven and rerunnable experiments. Explicit seeds, tracked configurations, and isolated results directories ensure that all computational findings can be independently reproduced.

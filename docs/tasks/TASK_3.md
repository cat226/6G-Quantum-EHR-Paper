# TASK 3 — Literature Evidence and Parameter Provenance

## 1. Objective

Establish a reproducible literature-evidence and parameter-provenance
framework for the research repository.

Task 3 does NOT implement the research simulation.

It establishes the structured evidence required to justify:

- QKD parameters
- PQC parameters
- network parameters
- EHR workload parameters
- healthcare/IoMT assumptions
- 6G/edge-network assumptions
- experimental comparison methodology

Every parameter used by later experiments must eventually be traceable
to either:

1. a verified literature source,
2. a clearly documented design assumption, or
3. a controlled experimental value generated by the project itself.

No parameter may silently become an "established fact."

---

## 2. Research Boundary

The project studies:

Latency-Aware Adaptive QKD-PQC Key Establishment for Electronic Health
Record Sharing in 6G-Edge Healthcare Networks.

The research contribution is evaluation and characterization of adaptive
QKD-PQC operation under varying QKD availability.

Task 3 must NOT claim:

- a new cryptographic primitive,
- a new QKD protocol,
- that QKD is universally superior to PQC,
- that hybrid QKD-PQC is itself novel,
- that 6G has a finalized mandatory security architecture,
- that any parameter is realistic merely because it appears plausible.

---

## 3. Evidence Classification

Every literature-derived fact must be assigned an evidence label.

Use exactly these categories:

### ESTABLISHED

A result/parameter is directly supported by a sufficiently verified
primary or authoritative source.

### REPORTED_RANGE

The literature provides a range rather than a single value.

The range must be preserved.

Do not replace it with an arbitrary midpoint.

### DESIGN_ASSUMPTION

The value is selected for the experiment because the literature does not
yet provide a sufficiently verified value.

The reason for selecting it must be documented.

### EXPERIMENTAL_VALUE

The value is generated or measured by this project.

It must not be represented as a literature fact.

### UNKNOWN

The evidence is currently insufficient.

UNKNOWN values must not silently enter final experiments.

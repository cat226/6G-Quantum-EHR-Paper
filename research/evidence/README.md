# Literature Evidence and Parameter Provenance

This directory stores the structured evidence required to justify the parameters used in the 6G-Quantum-EHR-Paper project.

As per Task 3, every parameter used by later experiments must eventually be traceable to a verified literature source, a clearly documented design assumption, or a controlled experimental value.

Currently, there is no verified literature data, so the data rows in the provenance files are kept empty.

## Files
- `literature_matrix.csv`: Overview of relevant literature.
- `parameter_provenance.csv`: Provenance data for all parameters.
